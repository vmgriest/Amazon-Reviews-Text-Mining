# Amazon Reviews Text Mining

A web application that compares multiple machine learning models for sentiment analysis on Amazon product reviews. Classifies reviews as **positive** or **negative** using four different algorithms.

## Models Compared

- Logistic Regression
- Naive Bayes
- Random Forest
- Support Vector Machine (SVM)

## Features

- Upload or paste review text for real-time classification
- Compare model performance side-by-side
- Clean Flask web interface
- Preprocessed Amazon reviews dataset included

## Technologies Used

- Python
- Flask
- scikit-learn
- HTML/CSS
- Pandas
